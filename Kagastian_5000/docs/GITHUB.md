# Entrega en GitHub

El proyecto de programacion esta en la carpeta `Kagastian_5000`.

La carpeta contiene el codigo Arduino, la interfaz Python y documentos breves de
conexion y estructura. Las evidencias completas en imagen y video estan en la
carpeta local `programacion` del equipo.

Para cargar el codigo en Arduino IDE se debe abrir:

```text
Kagastian_5000/arduino/pinguino_robot_final/pinguino_robot_final.ino
```
